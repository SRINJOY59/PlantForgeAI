# Equipment Datasheet — P-301 Centrifugal Pump

**Tag:** P-301
**Unit:** 300 (Product Rundown)
**Service:** Rundown transfer, stabilised product
**Governing standard:** OISD-STD-119 (rotating equipment condition monitoring)

## Design

| Parameter | Value |
|-----------|-------|
| Type | Horizontal centrifugal, single stage |
| Rated flow | 145 m3/hr |
| Rated head | 92 m |
| NPSH required | 3.2 m |
| Minimum continuous flow | 40 m3/hr |
| Seal | Single mechanical, API Plan 11 |
| Driver | 55 kW, 2-pole induction motor |

## Operating limits

- Minimum suction pressure: 1.2 barg. Below this the pump cavitates; do not
  operate against a closed or throttled suction.
- Maximum bearing temperature: 90 C.
- Vibration alarm: 4.5 mm/s overall; trip at 7.1 mm/s.

## Monitoring

P-301 is on the OISD-STD-119 condition-monitoring program. Baseline vibration
and bearing temperatures were recorded at INS-517. Trend monthly; a rising
vibration with stable process usually points at bearing or alignment, not the
process.

## Notes

Unlike P-101A, P-301 has an adequate suction margin in normal service. If
cavitation symptoms appear, check upstream level and strainer dP before
suspecting the pump.
