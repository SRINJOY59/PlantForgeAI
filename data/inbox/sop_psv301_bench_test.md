# SOP-U300-06 — Relief Valve PSV-301 Removal and Bench Test

**Unit:** 300 (Reaction loop relief)
**Equipment:** PSV-301 (set 14.0 barg)
**Governing standard:** IBR / OISD-STD-132 (pressure relief device testing)
**Revision:** 4 (2024-02)

## 1. Scope

Removal, bench testing, and re-certification of PSV-301. A statutory relief
device — its test record is a legal document, so the paperwork matters as much
as the wrench work.

## 2. Isolation

1. Confirm the loop can be protected by the standby path or is depressured.
2. A relief valve is never removed from a live, unprotected vessel. Verify the
   isolation with the shift supervisor before breaking any flange.

## 3. Bench test

1. Record the as-found lift pressure before any adjustment. For PSV-301 the
   as-found has come in early (IR-2026-021) — capture it, it is the evidence.
2. Test set pressure to 14.0 barg with a simmer margin within 3 percent.
3. Check seat tightness per API 527.
4. Re-certify and tag with the new test date and next-due date.

## 4. Records

File the test certificate against PSV-301 under OISD-STD-132. An early-lift
finding invalidates the previous certificate — the next-due date resets to the
new test, not the old schedule.
