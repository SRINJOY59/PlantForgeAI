# 8.1 Safety Instrumented System (SIS) Overview

Unit 300's SIS is a SIL-2-rated system (per IEC 61511 LOPA study, last revalidated 2023), physically and logically separate from the DCS (basic process control system). Key Safety Instrumented Functions (SIFs) protect against reactor runaway, overpressure, and loss of cooling.
