# XMV-12 (SC-101) — Reactor Agitator Speed VFD Setpoint

- **Tag:** SC-101 (DCS Output: XMV-12)
- **Description:** Variable Frequency Drive speed reference signal (4–20 mA / Modbus) for R-101 agitator motor.
- **Fail Position:** Fail Last Value (FLV) with UPS ride-through. Normal speed: 68% (81.6 RPM). Controls slurry mixing in [R-101](../02-equipment/r-101-reactor.md).
